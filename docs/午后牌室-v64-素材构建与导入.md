# 午后牌室 v64 · 素材构建与导入

## 重建游戏使用的房间、牌友与头像

使用 Blender **4.5.2 LTS**。把经美术确认的模型包解压到新的独立目录，以下五个文件应位于包根目录的指定位置；`场景/` 和 `预览/` 不参与导入。

```text
模型包根目录/
├── 午后牌室.blend
└── 角色/
    ├── cat.glb
    ├── fox.glb
    ├── panda.glb
    └── rabbit.glb
```

`.blend` 使用米制，纹理须打包。保留静态房间、桌体和椅子的对象名称；牌、中央盘、灯光和角色由游戏单独加载，不进入静态房间。桌体须含独立的 `Walnut tabletop` 和 `Empty green felt` 网格，毛毡使用 `Green playing felt` 材质。角色为纹理内嵌的 GLB 2.0，默认场景中的同名网格须绑定包含 `Chest`、`Head` 和左右 `UpperArm`/`Forearm`/`Paw`（`.L`、`.R` 后缀）的蒙皮骨骼；第一个动画片段是 `Seated tile reach`，并作用于该骨架。

先写入独立目录检查模型/头像，不覆盖游戏资源。生产发布也必须明确指定一个新的输出目录，例如：

```powershell
& 'D:\blender\blender.exe' --background --factory-startup --disable-autoexec --python-exit-code 1 --python scripts/import-room-pack.py -- 'D:\path\to\模型包' --output-dir 'out\room-pack-v64'
```

导入器只生成九个文件：`room/afternoon-room.glb`、四个 `companions/*.glb`（原样复制）和四张 `companions/portraits/*.png`（Cycles 透明渲染）。验证通过后，将这九个文件按相对路径复制到 `assets/mahjong-3d/glb/` 下对应的 Git 已跟踪位置，并在同一次提交中发布。输出目录不是完整的运行时资源树，不能整体替换 `glb/`；保留牌、中央盘、骰子、骰盅和源 `.blend` 等其他文件。不要删除 `--python-exit-code 1`，且须放在 `--python` 前，否则 Blender 执行脚本出错仍可能返回退出码 0。

可在临时副本中跑回归测试，不写入游戏资源：

```powershell
$env:BLENDER_BIN = 'D:\blender\blender.exe'
$env:ROOM_PACK_FIXTURE = 'D:\path\to\模型包'
node --test tests/room-pack.test.js
```

## 导入与发布范围

导入器先把 `.blend` 和四个角色 GLB 复制到输出目录旁的临时目录，后续校验、房间导出和头像渲染只使用这些副本。导出的默认场景必须包含独立的 `Walnut tabletop`、`Empty green felt`，以及墙体、椅子、柜、架、植物和吊灯。骰槽已包含在 `room/machine-console.glb` 中；可动骰盅由游戏单独加载 `glass-dice-cup.glb`，两者都不得进入静态房间。

PNG 校验不仅检查签名、块 CRC 和 zlib，还要求 192 × 192、RGBA8、无隔行，并确认解压后的每行过滤字节和 RGBA 扫描线长度完整且受大小上限约束。

`--output-dir` 必须指向尚不存在的新目录。验证或生成失败时不会创建发布目录；九个文件全部通过校验后才以同卷目录重命名发布。Windows 会拒绝重命名到已有目标；其他平台应使用独占的新路径，不要让并发进程创建同一目标目录。此步骤不替换正在使用的目录，也不改写运行时 URL；部署由发布流程单独完成。

## 隔离重建旧程序模型
旧程序模型没有当前游戏所需的蒙皮与动作，**不要复制到游戏资源目录**。需要旧场景时按顺序运行下列两条命令，所有模型、`.blend` 与渲染图均写到 `out/legacy-room/`：

```powershell
& 'D:\blender\blender.exe' --background --factory-startup --python-exit-code 1 --python scripts/build-companions.py
& 'D:\blender\blender.exe' --background --factory-startup --python-exit-code 1 --python scripts/build-afternoon-room.py
```
