### 1.2 视觉语言三条规则

1. **线描优先**：墨线是主体，填色只做低透明度块面（≤ 35% alpha）。不用渐变、投影、发光、拟真皮肤、二次元大眼。
2. **印章是署名不是装饰**：每个头像右上角有朱砂印；座位尺寸只有“印迹”（小方块），账号/资料区才出现白文单字。
3. **每张头像必须有“轮廓差异”**：发型/头饰/胡须/眼镜至少两项不同，保证不靠颜色也能区分四个座位（4.2、4.5 节）。

### 1.3 字体与文字

- 只用系统字体栈（`"Microsoft YaHei","PingFang SC",system-ui`，`视觉设计说明.md:24` 的既有约定）；印章字用 `Georgia, "Songti SC", "SimSun", serif` 也属于系统字体，**不加载远程字体**。
- 头像里除印章单字外**不放文字**（名字仍由 `.seatLabel` 文本承担）。

## 2. 设计 A：程序化牌友头像（Canvas，零图片）

### 2.1 构图与视觉规格（64×64 逻辑坐标）

每个头像在一个固定的 64×64 坐标系内绘制，CSS 决定最终显示尺寸；绘制函数只认逻辑坐标。

```
(0,0) ┌──────────────────────────────┐
      │  ╭────────────────────────╮  │  ← 外框：圆角 14，象牙纸 #f6efdf
      │  │        ○ 发髻/帽        │  │     1px 金线 rgba(201,176,106,.55)
      │  │      ╭───────╮          │  │  ← 月洞门：主色 18% 半圆（r=26）
      │  │      │ 眉 眼  │   ▣ 印  │  │  ← 朱砂印 8×8 @(50,50)
      │  │      │ 鼻 嘴  │          │  │
      │  │      ╰───┬───╯          │  │  ← 脸：21..43 × 17..41
      │  │        ╱ 领 ╲            │  │  ← 交领：墨线 + 主色 22%
      │  ╰────────────────────────╯  │
      └──────────────────────────────┘
```

| 层 | 内容 | 颜色/线宽 | 备注 |
|---|---|---|---|
| L0 底 | 圆角矩形 64×64，r=14 | 填 `#f6efdf`；边 1px `rgba(201,176,106,.55)` | 与象牙牌面同族 |
| L1 月洞 | 圆心 (32,30)，r=26 的半圆（下缘裁掉） | 主色 18% alpha 平涂 | 只做背景，不做渐变 |
| L2 肩领 | (12,64)→(24,46)→(40,46)→(52,64) 的交领折线 | 墨线 `#24332c` 1.15px；主色 22% 填 | 让头像“坐”在桌边 |
| L3 颈 | 28..36 × 47..54 | 象牙纸加深 6%（`#efe6d2`） | 无阴影 |
| L4 脸 | 三种脸型路径 | 墨线 1.15px，填 `#f7f1e2` | 见 2.2 |
| L5 发 | 六种发型，整块填墨 `#2b2b2b`（85% alpha） | 轮廓线同墨 | 轮廓必须一眼可分 |
| L6 五官 | 眉（2 笔）、眼（2 笔）、鼻（1 折线）、嘴（1 弧） | 墨线 1.0–1.2px | 眼距 10，眼高 29 |
| L7 须 | 四种 | 墨线 + 15% 填 | 与嘴不重叠 |
| L8 眼镜 | 三种 | 墨线 1.2px；圆框 r=4 | 画在五官之上 |
| L9 头饰 | 五种 | 墨线 + 主色 20% 填 | 画在发之上 |
| L10 印 | 8×8 方块 @(50,50)，内缩 1px | 底 `#a8452f`，印线 `rgba(246,239,223,.9)` | `<28px` 时只画方块，不画字 |

- **线端**：`lineCap=round`、`lineJoin=round`；**不画外阴影、不用 `shadowBlur`**。
- **背景透明**：外框以外的像素保持透明，让头像贴合深绿座位条。
- **LOD（细节档）**：显示尺寸 < 24px 时进入“简笔档”——省略耳、鼻、胡须纹理和月洞，只保留脸/发/眉/嘴/眼镜/头饰/印点；≥ 24px 画完整。目的是小尺寸不糊成一团。


- 每个参数**单独加盐**再哈希，避免“同一位低位相关”导致“长辫必配络腮”这类可见规律。

### 2.5 生命周期与 DOM 契约


- `renderSeat` 内插入点：`.seatName` 组装处（`3999-4012`），在 `appendSeatPersona` 之前执行，保证性格标签仍在名字之后。
- **缓存键**：`avatarKey` 命中且 `canvas.dataset.avatarPx === String(px)` 时**不重画**。`render()` 每帧会调用 `renderSeat`，这是硬要求（见 5.5 性能）。

- **失败降级**：`getContext('2d')` 返回 null → 不插 canvas，座位保持 v33 形态；`cfg.avatar==='off'` → 同样不插、不建 canvas、不执行哈希。

### 2.7 零图片/零依赖证据（t4 静态检查）

### 3.3 合成器：只用 stub 支持的最小节点集

`tests/audio-ui.html:13-45` 的音频桩只实现：`createGain`、`createBufferSource`、`createBiquadFilter`、`createOscillator`、`createBuffer`、`resume`，且 `AudioParam` 只有 `value`、`setValueAtTime`、`linearRampToValueAtTime`、`exponentialRampToValueAtTime`。因此：

| 允许 | 禁止（会打穿测试桩/破坏兼容） |
|---|---|
| `createOscillator` + `.frequency.value` | `.detune`、`setPeriodicWave` |
| `createGain` + 三种包络方法 | `setTargetAtTime`、`cancelScheduledValues`、`setValueCurveAtTime` |
| `createBiquadFilter`（lowpass/bandpass） | `createDynamicsCompressor`、`createConvolver`、`createWaveShaper`、`createStereoPanner`、`createDelay` |
| `createBufferSource`（复用既有 `noiseBuffer(a)`） | 新增长音频 `AudioBuffer` |

- 音色：**筝（pluck）**= triangle + 快速指数衰减 + 2.2kHz 低通；**笛（breath）**= sine + 慢起 + 1.4kHz 低通（只在结算“赢”句用一次）；**木鱼**= 0.25s 噪声 + 1.2kHz bandpass + 30ms 衰减；**低鼓**= sine 80Hz + 120ms 衰减。
- 每个音符独立建节点，`start/stop` 后自然释放；**不复用振荡器**（复用会算错相位）。
- 所有 `AudioParam` 写入用 `try/catch` 包裹，任何节点创建失败 → 本音符静默跳过，**不得抛错到 `render()`**。

### 3.4 三总线与现有 `sfx` 增益的关系

```
音效  hit()/tone() ──► SFX_GAIN    (cfg.sfxVolume/100,   默认 1.00) ─┐
音乐  musicTone/musicNoise ──► LAYER_GAIN (0.50/0.45/0.30)            │
                              └──► MUSIC_GAIN (cfg.musicVolume/100 × 0.9, 默认 0.36) ─┼──► destination
语音  系统 TTS  utterance.volume = cfg.voiceVolume/100（默认 0.80）   ← 不经过 WebAudio
```

- 两条 WebAudio 总线**各自独立**接到 `destination`，不互串、不叠压缩器；语音是第三条独立控制面。

- **不动 `SFX_GAIN`、`sfxBus`、`hit`、`tone`、`sfx(kind,info)` 的任何一行**：`tests/audio.test.js:55-65` 用逐字正则锁定了 `SFX_GAIN = AC.createGain()`、`function sfxBus(a) { return SFX_GAIN || a.destination; }` 和 `g.connect(sfxBus(a))` 至少 2 处。音乐必须**另写** `musicTone()`/`musicNoise()`，各自 `connect(MUSIC_GAIN)`。
- `audio()`（`3230-3246`）内追加 `MUSIC_GAIN` 的创建（**同一 try/catch**，失败则 `MUSIC_GAIN=null`，音乐退化为不可用但不报错）。既有 `SFX_GAIN` 代码一字不动。
- **语音总线不是 WebAudio**：TTS 走系统混音，无法接压缩器或总增益。所谓“三总线”是**三条独立的音量控制面**：`cfg.sfxVolume`、`cfg.musicVolume`、`cfg.voiceVolume`；不做母带压缩（测试桩不支持，且会改变既有音效响度）。
- **响度预算**：音乐单音包络峰值 ≤ 0.20，乘 `MUSIC_GAIN(0.36)` 后 ≤ 0.072 线性；音效单次峰值 ≤ 0.35（v33 既有）；音乐比最响音效低约 14 dB，保证“碰/胡”永远压得住音乐。duck 时再 ×0.35 → ≤0.025。
- **总开关**：`cfg.sound=false` 时音乐**不启动、不创建 AudioContext**（`audio()` 根本不被调用），与 `tests/audio-ui.html:209` 的 `contexts===0` 契约一致。

### 3.6 TTS ducking（自动让路）

- **触发点**：`speakAnnounce()`（`3314`）在 `s.speak(u)` 之前 `duckMusic(true)`；`u.onend/onerror`、`flushAnnounce()` 队列清空、`cancelAnnounce()` 之后 `duckMusic(false)`。教练语音 `coachSpeak()` 同样调用。
- **数值**：duck 目标 = 基准增益 × 0.35；下潜 `linearRampToValueAtTime(target, now+0.12)`；恢复 `…(base, now+0.30)`，且在语音结束后再等 120ms 才恢复，避免句尾被音乐顶上来。
- **兜底**：某些浏览器 `onend` 不触发。`duckMusic(true)` 同时启动一个 **一次性** `setTimeout`（估算时长 `clamp(1200, 180 + 160×字数, 6000)` ms）到点恢复；`onend` 提前恢复时清掉该定时器。用 `DUCK.token` 计数，避免并发语音提前恢复。
- **不 duck 音效**：音效是事件性的，压低会削弱反馈；只有连续音乐让路。
- 页面隐藏/音乐关闭/TTS 未启用时，`duckMusic` 直接返回（不建定时器）。

### 3.8 调度与资源预算

- **一个** `setInterval(musicTick, 200)`；`musicTick` 只做 O(1) 计算：以 `anchor = AC.currentTime` 为基准，`elapsed = AC.currentTime - anchor`，`bar = floor(elapsed / 3.3333) % 8`，把未来 0.35s 内该响的音符排进去。**不用 `setTimeout` 逐个音符**，不用 `requestAnimationFrame`。
- 时间漂移：`Math.abs(elapsed - expected) > 0.25s`（如系统休眠）时重设 anchor；不补播。
- 并发：同时存活的振荡器 ≤ **12**（旋律 1–2 + 低音 1 + 打击 1–3 + 结算短句 ≤ 5，留 2 个余量）；每 tick 最多排 4 个音符。
- 内存：乐谱表 < 4KB；不新建 AudioBuffer（木鱼复用 0.25s `NOISE`）；常驻对象仅 4 个 GainNode + 1 个 interval。
- 目标：中端手机 CPU 增量 < 2%，首次出声 < 100ms，内存增量 < 1MB。
- 所有入口 `try/catch`；`AC.state==='suspended'` 时先 `resume()`（不等待 Promise）。

   - 风险句：`main` 保持 `feedback.main` 不变，`detail = feedback.detail + '｜' + line`；

### 4.6 教练语音（可选 TTS，默认关）

- 新键 `cfg.coachVoice`（`'off'` 默认 / `'on'`），**不复用** `cfg.voice`：报牌与教练语音是两件事，混用会让 `audio-ui.html` 的 `ALLOWED` 白名单测试失败（教练句含“进张/安全/危险”等非报牌词）。
- 独立函数 `coachSpeak(text)`：
  - 前置：`cfg.sound && cfg.coachVoice==='on' && !pageHidden() && !AC被禁`；
  - 文本：只取 `say:true` 的句子；长度 ≤ 14 字；**不写 `#announce`**（视觉上已经显示在 `#coach`/结算弹窗里）；
  - 嗓音：复用 `zhVoice()`；`lang='zh-CN'`、`rate=1.0`、`pitch=1.0`、`volume=cfg.voiceVolume/100`；
  - 队列：最多排 1 条；若报牌 TTS 正在播（`TTS.speaking`），**丢弃**教练句，绝不打断报牌；
  - 与 `cancelAnnounce()` 的关系：换局/隐藏/关闭语音时调用 `coachCancel()` 清自己的队列；`speechSynthesis.cancel()` 由既有 `cancelAnnounce` 统一负责，避免双重 cancel；
  - 失败静默：无 `speechSynthesis`、无中文嗓音、`speak()` 抛错 → 全部吞掉。
- 设置行文案：`教练语音（系统中文语音，默认关闭，与报牌共用语音音量）`。
