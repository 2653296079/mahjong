# 交付说明：从《棋牌王 3D》借鉴的两项增强

日期：2026-11-04
对象：项目负责人 / 后续维护者
状态：已完成实现、独立验证与两轮审查（t1–t8），未推送 GitHub、未部署。

## 1. 一句话结论

在不改动规则、发牌、结算和联机协议的前提下，给单机练牌增加了 **6 种可观察的电脑对手性格**，以及 **16 类程序合成音效 + 可选中文语音报牌**；默认全部关闭，原有测试与牌谱金样签名保持不变。

## 2. 从 APK 学到什么、没有学什么

参考对象是 `棋牌王3D_0.41.0.apk` 的 WebView 层（APK 的 3D 由原生 Vulkan 渲染，网页只做透明 overlay）。本次只提炼机制并原创实现：

- 学到：AI 人格 = 一套基础 AI + 参数层（不同风险/鸣牌/过胡倾向），以及“事件驱动的音效/报牌”分层。
- 没有复制：APK 的美术、语音、文案、预置统计表（TEN/DEAL/PWIN）、规则变体和成段代码；也没有搬它的“运势改牌”这类机制。

详细拆解见 [借鉴-棋牌王3D.md](借鉴-棋牌王3D.md)，落点审计见 [项目增强落点审计.md](项目增强落点审计.md)，需求与验收见 [增强方案-棋牌王3D启发.md](增强方案-棋牌王3D启发.md)。

## 3. 玩家可见的变化

### 3.1 对手性格（设置 → 对手性格）

| 值 | 名称 | 可观察倾向 |
| --- | --- | --- |
| steady | 稳健 | 先保听牌，不轻易冒险 |
| raider | 猛攻 | 有碰就碰，抢速度 |
| turtle | 龟缩 | 宁可不听，也不点炮 |
| gambler | 赌徒 | 小胡看不上，敢放过 |
| mimic | 跟打 | 盯着上家，跟同花色 |
| schemer | 算计 | 只按牌效，精打细算 |

- 默认 `关闭`：不写 persona 字段、不消耗牌墙 RNG，行为与原版完全一致。
- `经典三人组`：三名电脑分别使用稳健 / 猛攻 / 龟缩。
- `按名字随机（6 种）`：按座位名确定性分配（不是每局重抽）。
- 座位旁显示 2 字性格标签；鼠标悬停可看性格说明。
- 只影响单机电脑的决策倾向；联机模式不启用，服务端零改动。

### 3.2 音效与报牌（设置 → 音效 / 语音报牌）

- 16 类事件音效：洗牌、发牌、摸牌、出牌、碰、杠、胡、结算、鸟、骰子等，全部 WebAudio 程序合成，**零外部音频文件**。
- 音效总开关 + 音效音量 + 报牌音量。
- 语音报牌（默认关）：
  - `只报关键`：轮到你、自己与下家出牌、碰杠胡；
  - `全部公开信息`：再加对家/上家出牌与自己的摸牌。
- 语音使用系统中文嗓音，无 TTS / 无中文嗓音 / 音效关闭时静默降级；页面切到后台时全部静音且恢复后不补播。
- 联机模式没有 `record` 事件流时自动回落到原音效，不报牌。

## 6. 如何应用与发布

本工作区 `D:\mahjong\repo` 是 GitHub `main` 快照（d881826）的直接文件树，不是 git 仓库；同目录另附补丁 `..\增强-棋牌王3D.patch`。

3. 提交并推送 `main`；`sw.js` 已升到 `zmj-v33`，已安装旧页的用户会在下次访问时更新缓存。
4. GitHub Pages 构建完成后打开 https://2653296079.github.io/mahjong/ ，在“设置”里试 `经典三人组` + `只报关键`。

本轮未执行推送或部署，按约定需由你确认后自行发布。

## 7. 已知限制与后续建议

- 联机模式语音报牌静默（没有 `record` 事件流），设置页未特别注明“仅单机”；如需联机报牌，应基于公开视图增量另做，不动协议。
- TTS 依赖系统中文嗓音；桌面 Edge/Chrome 已用 CDP/探针验证，真人读屏与真机未手测。
- 3D 牌桌的音效覆盖以静态/集成检查为主，未做逐像素与性能基准。
- 语义小瑕疵：设置项“按名字随机（6 种）”实际是确定性哈希分配，可改为“按名字分配”。
- 若后续改动 `sw.js` 缓存版本，记得同步 `tests/offline.test.js` 的期望数组（本次已示范）。
