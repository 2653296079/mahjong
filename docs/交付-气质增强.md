## 3. 玩家可见的变化

### 3.1 牌友头像（设置 →「牌友头像」，默认开）

- 脸型／发型／胡须／眼镜／头饰／主色／朱砂印七组参数由昵称与座位加盐哈希确定性派生，绘制分 10 层（象牙纸、月洞、交领、脸、发、须、镜、头饰、朱砂印），同一局四家不撞脸，刷新与重开不变脸。
- 尺寸：桌面 30px，随屏宽降档 28／26／22px；窄屏与低高度横屏 16px；三维胶囊内 26px（手机 18px）。730px 以下、以及窄屏的侧家沿用既有“只留名字”策略。
- 纯装饰：`aria-hidden`、`tabindex="-1"`、不新增可点击区域，不只靠颜色区分；无 2D context 时静默降级回文字座位。
- 关闭后座位 DOM 与 v33 逐字一致、0 个 canvas；三维下开→关→开即时 **4→0→4**。

### 3.2 背景音乐（设置 →「背景音乐」默认关，「音乐音量」默认 40）

- 原创 D 宫五声音阶，72 BPM、8 小节（约 26.7 秒）循环，筝／笛／木鱼／低鼓全部 WebAudio 合成；按牌局平静／紧张／收束三档切换，和牌与荒庄有短句收束。
- 默认关闭；开启后音量 0–100 独立调节、拖动即时生效（`MUSIC_GAIN` 与音效总线分离，40 → 0.36）。
- 语音报牌时压低到 0.35 倍，句尾、`speak()` 异常与兜底定时器三条路径都会恢复；页面隐藏即停止，回前台从新小节继续、不补播。
- 「音效」总开关关闭时不创建音频上下文，也不产生任何音符。

### 3.3 教练短句（设置 →「教练提示」，默认开）

- 等待／答错／点炮风险／鸟牌／复盘五类共 70 条原创短句（各 14 条，逐条带可念标记）；本轮只做可视文本。
- 落点：替换 `#coach` 等待分支三行；向出牌反馈追加一句；结算里用 `textContent` 写入独立节点 `#settleCoach` / `#reviewCoach` 各一行。
- 不写 `#hint` / `#miniHint` / `#announce` / `#log`，不产生任何新的 `speak()`；测验模式不泄题；同句至少间隔 5 秒并避开上一句。
- 关闭后逐字回到 v33 的等待与反馈文案，结算无新增节点。

## 7. 如何应用与发布

本工作区 `D:\mahjong\repo` 是 GitHub `main` 快照（d881826）的直接文件树，不是 git 仓库；同目录另附补丁 `..\增强-气质版.patch`（含上一轮 v33 与本轮 v34）。

1. 在本地 `mahjong` 仓库执行 `git apply --check ..\增强-气质版.patch`，确认可应用后再 `git apply`；或直接把上表文件复制进仓库根目录。本轮已在 `mahjong-main.zip` 的干净解压树上验证：`git -c core.autocrlf=false apply --check` 与 `git apply` 均退出 0，应用后 28 个文件与 `repo/` 逐字节一致（SHA256）。若本机全局 `core.autocrlf=true`，直接 apply 会按 Git 规则在入仓时归一化换行，不影响提交内容。
2. 运行 `node tests/run-checks.js --browser`，确认全绿。
3. 提交并推送 `main`；`sw.js` 已升到 `zmj-v34`，已安装旧页的用户下次访问会更新缓存。
4. GitHub Pages 构建完成后打开 https://2653296079.github.io/mahjong/ ，在“设置”里试头像、背景音乐与教练提示。

本轮未执行推送或部署，按约定需由项目负责人确认后自行发布。

## 8. 已知限制与后续建议

- **联机结算不播收束短句**：联机结算的 tick 早退，cadence 只在单机与训练结算播放；本轮按文档口径接受，若要对齐需另改结算调度。
- **教练 TTS 未接**：`tests/audio-ui.html` 的运行时报牌白名单会校验每条 `speak` 文本，教练句需要独立白名单页面，不能复用 `cfg.voice`；可念标记已保留，供后续实现。
- **账号面板头像未做**：需求中的 72px 头像属可选，本轮未实现。
- **`risk≥0.15` 的真实采样界面**未单独构造，目前由纯函数与静态断言覆盖。
- **≤820 侧家头像隐藏**是审查后经负责人确认的修法：730×545 只显示两枚头像，换取行高只增 5.5px；若后续收紧桌面布局可重估。
- **`tests/table-3d-ui.html` 对机器负载敏感**：等待条件仍是 `machineBusy=0` 且 14 个点击区就绪，超时放宽到 90s，并在 `phase=ready` 卡住超过 30s 时点“跳过动画”兜底；未削弱原断言，建议发版前在安静环境跑一次。
- **包体 +39,068 B**（404,020 → 443,088 B，`server.js` gzip 实测 134,314 B）：仍在单文件、零外链、零构建约束内，接受不压缩；若后续逼近 500KB 再考虑合并重复 CSS 与短句表。
- 原创复核脚本与 APK 台词样本保存在仓库外的 `D:\mahjong\out\`，不入库、不随补丁分发。
