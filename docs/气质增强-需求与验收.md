## 4. 实现契约（可直接照做的最小集合）

### 4.1 A 头像

- **纯数据 + 纯函数**：`avatarHash(text)`（FNV-1a，`Math.imul`）、`avatarParams(name, isMe)` 返回 `{face,hair,beard,glasses,hat,accent,stamp}`；哈希输入 `String(name).slice(0,24)`，**禁止 `Math.random()`**；每个参数单独加盐（`name + '#face'` 等）。
- **参数值域**（t1 附录 A，测试会逐项断言）：`face 0..2 / hair 0..5 / beard 0..3 / glasses 0..2 / hat 0..4 / accent 0..5`；`hair===3（长辫）` 时 `beard` 强制 `0`。
- **真人座位的名字来源**：`pl.name`；若 `identityName()` 不是 `'访客'` 且是本座位，用账号名。空名、`座位N`、`电脑N` 必须有稳定结果，不得抛错。
- **`persona` 不参与头像参数**（性格开关重开一局不该换脸）。
- **重绘节流**：`avatarKey(name,isMe,px)` 命中且 `canvas.dataset.avatarPx === String(px)` 时不重画；`render()` 每帧都会调 `renderSeat`，这是硬要求。`window.__zmjAvatar.debug = { draws: 0, skips: 0 }` 供测试计数。
- **失败降级**：`getContext('2d')` 为 `null`、或 `cfg.avatar!=='on'` → 不建 canvas、不哈希，座位 DOM 与 v33 一致。
- **DPR**：`px = clamp(64, round(cssPx * min(dpr,2)), 128)`，`ctx.scale(px/64, px/64)`，`imageSmoothingEnabled = true`。

### 4.2 B 音乐

- **数据表必须是纯数据字面量**（Node 测试会正则切片并求值，见 5.2）：`var MUSIC_SCORE = { lead: [...], bass: [...], perc: {...}, cadence: {...} };`，每项 `{deg, oct, beat, len}`，逐音照抄 t1 3.2。**表内不得出现函数、DOM、模板字符串**。
- **合成白名单**（只用 `audio-ui.html:13-45` 桩支持的节点/方法）：`createGain`、`createOscillator`、`createBiquadFilter`、`createBufferSource`、`createBuffer`、`resume`；`AudioParam` 只用 `value`、`setValueAtTime`、`linearRampToValueAtTime`、`exponentialRampToValueAtTime`。
- **禁用**：`setTargetAtTime`、`cancelScheduledValues`、`setValueCurveAtTime`、`.detune`、`setPeriodicWave`、`createDynamicsCompressor`、`createConvolver`、`createWaveShaper`、`createStereoPanner`、`createDelay`。
- **总线**：`MUSIC_GAIN.gain.value = cfg.musicVolume/100*0.9`（默认 40 → 0.36）；每个音符 `connect(MUSIC_GAIN)`；**不碰 `SFX_GAIN`/`sfxBus`/`hit`/`tone`/`sfx` 任何一行**。
- **分层只读公开字段**：`game.drawsLeft()`（开局≈12，紧张层阈值 **≤4**）、`H.players[i].melds.length` 合计（≥3）、`H.over`。音乐代码段内不得出现 `concealed|shanten|ukeire|dealIn|risk|opponents`（静态断言）。
- **调度**：1 个 `setInterval(musicTick, 200)`；`musicTick` O(1)，以 `anchor = AC.currentTime` 为基准，把未来 0.35s 内该响的音排进去；**每 tick 最多 4 个音符**；同时存活振荡器 **≤12**；漂移 `>0.25s` 重设 anchor 不补播。
- **生命周期**：默认 `'off'` 时**不建 AC、不建定时器、无振荡器**；`musicStop(fade)` 清 interval、层增益降到 0，`MUSIC_GAIN` 保留；`cfg.sound===false` 时 `musicStart` 早退。
- **ducking**：目标 = 基准 ×0.35；下潜 0.12s、恢复 0.30s，句尾再等 120ms；`DUCK.token` 计数防并发；兜底一次性 `setTimeout(clamp(1200, 180+160×字数, 6000))`；**不 duck 音效**。
- **测试钩子**：`window.__zmjMusic = { version:1, score: MUSIC_SCORE, state: function(){ return { layer: ..., running: ..., base: ..., ducked: ... }; }, debug: { starts: 0, stops: 0, timers: 0, ducks: 0 } }`。

### 4.3 C 文案

- **数据表必须是纯数据字面量**：`var COACH_LINES = { wait: [{id,text,say}], wrong: [...], risk: [...], bird: [...], review: [...] };`，70 条逐字照抄 t1 4.2。**表内不得出现函数、DOM**，`say` 只能是布尔。
- **纯函数选取**（确定性、无 `Math.random()`）：
  - `coachPick(cat, handNo, turn)` **保持纯函数**（只做 FNV 哈希取模），`window.__zmjCoach.pick` 即它，测试可直接断言确定性；
  - 显示层 `coachNextIndex(cat, handNo, turn)` 用 `coachLastIdx[cat]` 记录上次索引，命中时 `+1` 顺延，保证**任何相邻两次都不重复**；5 秒锁仍在 `coachLine` 统一处理。

```js
function coachNextIndex(cat, handNo, turn) {
  var list = COACH_LINES[cat] || [];
  if (!list.length) return -1;
  var i = avatarHash(cat + '|' + handNo + '|' + turn) % list.length;
  if (i === coachLastIdx[cat]) i = (i + 1) % list.length;   // 不连续重复
  coachLastIdx[cat] = i;
  return i;
}
```

- **频率**：同类 5s 内不换（`coachLastAt[cat]`）；等待类每 2 个摸打回合最多 1 条；**不加定时器**。`#coach` 是 `role="status" aria-live="polite"`，频繁变化会骚扰读屏。
- **落点**：
  - 等待（`renderCoach` else 分支）：替换 `eyebrow/main/detail` 三行文本，HTML 结构不变。
  - 风险（feedback 且 `feedback.risk >= 0.15`）：`main` 不变，`detail = feedback.detail + '｜' + line.text`。
  - 答错（feedback、`grade==='warn'`、风险 <0.15）：`main = line.text`，`detail = '『' + feedback.main + '』' + feedback.detail`（**原数字与结论必须保留**）。
  - 鸟牌（`showSettlement`，`r.birds && r.birds.length` 且 `r.type!=='draw'`）：`#settleCoach`。
  - 复盘（`showSettlement`，`handExtra && handExtra.reviews.length`）：`#reviewCoach`；有 ≥3 条回顾时优先 `V01`。
- **`discardReview` 的 `risk` 字段**：在既有 `if (cfg.analyze) { try { … } }` 块内顺带取值 `riskProb = res ? res.dealIn(kind).prob : null`，返回对象追加 `risk: riskProb`；**不改既有 6 个字段**；`cfg.analyze===false` 或采样不可用时为 `null`。
- **测试钩子**：`window.__zmjCoach = { version:1, lines: COACH_LINES, pick: coachPick, last: function(){ return { cat: ..., id: ..., text: ... }; } }`。
