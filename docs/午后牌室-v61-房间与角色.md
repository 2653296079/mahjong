# 午后牌室 v61 · Blender 房间与角色

## 可编辑来源

完整可编辑概念工程见模型包：`assets/mahjong-3d/glb/room/afternoon-room.blend`。v61/v62 Blender 构建脚本只输出旧程序概念模型到 `out/legacy-room/`，不更新游戏使用的角色或房间模型；旧模型不含游戏骨骼动作，不适合作为运行时资源。运行时批准包输入契约、隔离测试及导入命令见[午后牌室 v64 素材构建与导入](午后牌室-v64-素材构建与导入.md)。

## 当前实现

猫、狐、熊猫、兔坐在四个座位，身体和椅子由 Blender 制作。手臂采用游戏端分段关节控制，连接肩、肘与爪子。接牌有伸手准备阶段，拖牌和选牌时爪子跟随同一牌模，出牌触桌后释放。

待机有轻微转头、熊猫托腮和兔子手部动作。减少动态效果时停用待机动作。

房间包括木地板、窗框、简化绿植、墙面、柜架、书、盆栽与吊灯。

## 当前限制

第一版可运行场景与概念图相比仍较简化。尚未制作精细毛发、完整骨骼蒙皮和手指关节动画；手部是可活动的分段模型。开局批量发牌演出仍沿用原实现，尚未全部改为逐张角色抓取。

只有自己的明牌与公开牌河用于动作目标，不向角色模块传入对手暗牌牌种。
