# 仿真麻将路线（v41 起）

日期：2026-11-07
定位：在现有规则、联机、账号、训练分析不变的前提下，把「操作手感」逐步做成真人牌桌的样子。优先级按收益/风险排序，一次一个可验收点。

## 已经具备的真人化底子

- 三维麻将机：收牌入机、洗牌、四方升墙、中央骰盘、真人庄家摇骰/点击掷骰、三轮四张抓牌、庄家跳牌、自己的牌翻面接牌。
- 三维接牌：摸牌后需要点击「接牌」或点实际摸入的那张，二维仍自动接牌。
- 手牌：点一下抬起、再点同一张确认；手牌列内拖动理牌；Alt+左右键移动；同种牌逐张选择。
- 牌河：中央按真实先后累积，来源边框/图例；碰杠取走的牌移到副露区。
- v41：把手牌直接拖到中央牌河，松手即出牌（二维/三维共用）。

## P1 · 移动端 UI

- 390×844 手牌 14 张：v48 实测 360/390/430 全部落在手牌区内且无隐藏溢出（360 时单张约 22px 偏小但可见），确定「缩放全部可见」策略；牌面可读性优化留给后续单独评估。
- 竖屏触控与安全区：✅ v49——顶栏/摸牌/更多菜单按钮 44px，牌墙药丸视觉 32px + 有效命中 ≥44px，四边 `env(safe-area-inset-*)` 接入；360/390 无横向溢出、底栏不压手牌。
- 横屏触控：✅ v50——高度 ≤500px 视口把顶栏/更多菜单/摸牌接牌按钮抬到 44px，操作栏 56px；844×390 无横向溢出、底栏在视口内；矮横屏下牌墙药丸按既有布局隐藏、摸牌走按钮。
- 手机拖拽的抬升偏移（当前 38px）与震动反馈在真机验收。

## P2 · 性能

- 手牌/牌河避免整桌重画；拖拽期间冻结无关面板更新。
- 3D 低帧设备按可见进度推进、后台暂停已有基础；补一次长牌河/多副露的帧率记录。

## P3 · 音效

- 摸牌、落桌、碰杠、胡、翻鸟的最小集已有程序合成；补拖拽「拿起/落桌」两类轻音，受「音效」总开关与静音控制。
- 教练短句仍只走可视文本，不接 TTS。

## P4 · AI 续研

- 与操作层分开；任何 AI 改动必须另起实验与指标，不能混进 UI 提交。
- 现有采样风险/牌效讲解保持只读公开信息，不用未校准概率作承诺。
