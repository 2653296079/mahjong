# 转转麻将 · 练牌室

一个可以离线玩的转转麻将练习器。你对战三位电脑玩家，边打边看牌效、公开信息推算的放铳风险，并在每次出牌后看到简短复盘。游戏不需要账号或后端。

**在线玩：** https://2653296079.github.io/mahjong/

## 开始

- 电脑：打开在线地址，或直接用浏览器打开 `index.html`。
- 手机：用 Safari 或 Chrome 打开在线地址，可以添加到主屏幕。竖屏和横屏均可玩。
- 局域网试玩：在项目目录运行 `node server.js 8000`，同一 Wi-Fi 的手机访问终端显示的地址。Windows 也可以双击 `启动手机服务器.bat`。

轮到你时点击手牌打出。触屏设备需要点两次同一张牌，避免误触。可碰、杠、胡时操作栏会出现按钮。键盘快捷键：`H` 胡、`P` 碰、`G` 杠、`空格` 或 `Esc` 过。默认不限时；限时模式可在设置中开启。打开弹窗、手机牌况抽屉或切到后台时，倒计时会暂停。

## 规则

| 项目 | 本游戏采用的规则 |
| --- | --- |
| 牌 | 万、条、筒各 1–9，每种四张，共 108 张；没有字牌 |
| 行牌 | 不能吃，可以碰、暗杠、大明杠、补杠 |
| 胡牌 | 四组面子加一对乱将，或小七对；小七对和平胡同价 |
| 鸟 | 每局预留六张鸟牌；1、5、9 算中鸟。0 只为 30 元，1–5 只为只数 × 5 元，6 只为 60 元 |
| 收炮 | 放炮者付 `5 元 + 鸟钱` |
| 自摸 | 其他三家各付 `10 元 + 鸟钱` |
| 杠钱 | 暗杠三家各付 10 元；大明杠放杠者付 15 元；补杠三家各付 5 元 |
| 其他 | 可一炮多响；补杠不可抢杠；放过一次炮后，在自己摸牌前不能再胡炮；荒庄无赔付 |
| 转转 | 默认胡牌者下桌、等待区玩家上桌；可在设置中关闭 |

这些是本练习器的牌桌规则，不代表所有地区的麻将规则。

## 练习功能

- **牌效提示：** 显示向听数、有效进张和候选弃牌。进张的“未见张数”只按你的手牌与公开牌计算，不读取对手暗牌；它不等于牌墙里确定存在的张数。
- **局势分析：** 对对手手牌做随机采样，估计听牌和放铳风险。百分比是模型推断，会受采样数与假设影响，不能当作已知事实。
- **每手复盘：** 出牌后显示与牌效推荐的差异，以及该张牌的采样风险。
- **防守道场：** 在中后盘局面里练习选弃牌，并比较候选牌的进张与风险。
- **统计和牌谱：** 训练统计保存在当前浏览器的本地存储；本次游戏的牌谱可导出、逐步回放。清除浏览器数据会清除本地统计。
- **离线使用：** 通过 HTTPS 访问后，Service Worker 会缓存页面供离线打开。

## 开发与验证

项目无构建依赖。页面、样式、核心引擎和交互代码都在 `index.html`；`server.js` 提供本地静态服务器，`sw.js` 提供离线缓存，`tests/core.test.js` 检查核心规则。

```bash
node --test tests/core.test.js
node server.js 8000
```

修改页面后请同步递增 `sw.js` 中的缓存版本，以便已安装的网页应用取得新内容。GitHub Pages 从 `main` 分支的仓库根目录部署。发布步骤见 [部署说明.md](部署说明.md)。
