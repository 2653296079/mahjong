# 转转麻将 · 练牌室

一个可以离线玩的转转麻将练习器。你对战三位电脑玩家，边打边看牌效、公开信息推算的放铳风险，并在每次出牌后看到简短复盘。也可以开一间房，和朋友一起打（人数不够由电脑补位）。游戏不需要账号。

**在线玩：** https://2653296079.github.io/mahjong/

## 开始

- 电脑：打开在线地址，或直接用浏览器打开 `index.html`。
- 手机：用 Safari 或 Chrome 打开在线地址，可以添加到主屏幕。竖屏和横屏均可玩。
- 局域网试玩：在项目目录运行 `node server.js 8000`，同一 Wi-Fi 的手机访问终端显示的地址。Windows 也可以双击 `启动手机服务器.bat`。

轮到你时点击手牌打出。触屏设备需要点两次同一张牌，避免误触。可碰、杠、胡时操作栏会出现按钮。键盘快捷键：`H` 胡、`P` 碰、`G` 杠、`空格` 或 `Esc` 过。默认不限时；限时模式可在设置中开启。打开弹窗、手机牌况抽屉或切到后台时，倒计时会暂停。

## 和朋友一起打（联机）

联机需要一台跑着本项目的电脑当服务器，网页本身托管不了牌局。

1. 在项目目录运行 `node server.js 8000`（Windows 可双击 `启动手机服务器.bat`），终端会打印局域网地址。
2. 所有人用浏览器打开**同一个地址**，点工具栏最左边的「联机」，填名字进房间（房间号留空就是新开一间）。
3. 房间里点「开始对局」。座位不够 4 个人时，空位由电脑补上；等待区也会放两个电脑，这样转转轮换时有人上桌。
4. 点「复制邀请链接」发给朋友，对方打开就能直接进同一间房。

想从外网一起打，就把这台电脑的 8000 端口映射出去，或者用内网穿透工具；手机用户在页面里填那台电脑的地址即可。

关于联机的几点说明：

- **牌局跑在服务器上**：服务器发牌、判定胡牌和算钱，浏览器只提交自己的操作。所以每个人拿到的都是同一副牌，也不会出现「本地改一下就能作弊」。
- **服务器只发你自己的暗牌**：对手的手牌只发张数，牌墙只发剩余张数，鸟牌在结算前不下发。客户端的提示、进张、放铳概率仍然照常可用，因为那些功能本来就只用公开信息推算。
- **掉线不炸局**：有人掉线时电脑先替他打，他重连（同一个浏览器打开即可）后接着自己打，座位和手牌都还在。
- **挂机会被托管**：一个座位超过 60 秒没有操作，服务器替这一手做决定，避免一个人把整桌卡住。
- 联机打的牌局同样计入本机的训练统计和牌谱。

## 规则

| 项目 | 本游戏采用的规则 |
| --- | --- |
| 牌 | 万、条、筒各 1–9，每种四张，共 108 张；没有字牌 |
| 行牌 | 不能吃，可以碰、暗杠、大明杠、补杠 |
| 胡牌 | 四组面子加一对乱将，或小七对；小七对和平胡同价 |
| 鸟 | 每局预留六张鸟牌；1、5、9 算中鸟。0 只为 30 元，1–5 只为只数 × 5 元，6 只为 60 元 |
| 收炮 | 放炮者付 `5 元 + 鸟钱` |
| 自摸 | 其他三家各付 `10 元 + 鸟钱` |
| 杠钱 | 暗杠三家各付 10 元；大明杠放杠者付 15 元；补杠三家各付 5 元 |
| 其他 | 可一炮多响；补杠不可抢杠；放过一次炮后，在自己摸牌前不能再胡炮；荒庄无赔付 |
| 转转 | 默认胡牌者下桌、等待区玩家上桌；可在设置中关闭 |

这些是本练习器的牌桌规则，不代表所有地区的麻将规则。

## 练习功能

- **出牌讲解：** 对每个候选弃牌先比较向听，再比较有效进张；列出每种可进的牌及未见张数。一向听时会演示下一摸后怎样弃牌，形成更宽的听口。
- **概率依据：** 在“未见牌随机分布”的简化假设下，下一次自己摸到有效牌的基准概率为 `未见有效张数 ÷ 未见总牌数`。未见牌包含对手暗牌和预留鸟牌，不能当成牌墙中确定存在的牌；对手行动和后续改牌会改变概率。
- **局势分析：** 对对手手牌做随机采样，估计听牌和放铳风险。百分比是模型推断，会受采样数与假设影响，不能当作已知事实。
- **每手复盘：** 出牌后显示与牌效推荐的差异，以及该张牌的采样风险。
- **防守道场：** 在中后盘局面里练习选弃牌，并比较候选牌的进张与风险。
- **统计和牌谱：** 训练统计保存在当前浏览器的本地存储；本次游戏的牌谱可导出、逐步回放。清除浏览器数据会清除本地统计。
- **离线使用：** 通过 HTTPS 访问后，Service Worker 会缓存页面供离线打开。

## 开发与验证

项目无构建依赖。页面、样式、核心引擎和交互代码都在 `index.html`；`server.js` 提供本地静态服务器和联机服务，`sw.js` 提供离线缓存。

联机的服务端代码在 `server/`，它**不维护第二份引擎**：`server/rooms.js` 启动时直接从 `index.html` 里取出内联的引擎来跑，所以浏览器和服务器永远是同一份规则实现。

```bash
node --test tests/core.test.js tests/multi.test.js   # 核心规则 + 多人座位/轮换
node server/test-ws.js                                # 自写的 WebSocket 协议
node server/test-rooms.js                             # 房间流程 + 防作弊 + 掉线托管
node server/test-online.js                            # 真 WebSocket 客户端打完整局
node tests/browser-online.js                          # 真浏览器双开联机（需要 Edge，可选）
node server.js 8000
```

修改页面后请同步递增 `sw.js` 中的缓存版本，以便已安装的网页应用取得新内容。GitHub Pages 从 `main` 分支的仓库根目录部署。发布步骤见 [部署说明.md](部署说明.md)。
