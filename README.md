# 转转麻将 · 练牌室

把湖南转转麻将（108 张、不能吃、可碰可杠、扎鸟计分）完整实现出来的**单文件网页游戏**，
带 EV 决策提示与复盘记录，用来练牌。

## 在线玩

https://2653296079.github.io/mahjong/

手机浏览器打开 → 分享 → 添加到主屏幕，即可全屏当 App 用。

## 已实现的规则（按本地牌桌确认版）

| 项目 | 规则 |
|---|---|
| 牌 | 108 张（万/条/筒 1-9 各 4 张），无字牌 |
| 吃碰杠 | **不能吃**，可碰；暗杠 / 大明杠 / 补杠 |
| 胡牌 | 4 组 + 1 对（乱将），或小七对（与平胡同价） |
| 鸟 | 胡牌后翻 6 张，摸到 1/5/9 各算一只 |
| 鸟钱 | 0 只 = 30 元，1~5 只 = 只数 × 5 元，6 只 = 60 元 |
| 收炮 | 放炮者付**鸟钱**（5 元底 = 1 只鸟的价钱，已含在内） |
| 自摸 | 三家各付「基础 10 元 + 鸟钱」（0 只鸟 → 每家 40 元） |
| 杠 | 暗杠每家 10 元 / 大明杠放杠者 15 元 / 补杠三家各 5 元 |
| 补杠 | 只能自摸到第 4 张，**不可被抢杠** |
| 杠上开花 | 按自摸算 |
| 过水 | 放弃一次的炮后，自己摸牌前不能再胡炮 |
| 荒庄 | 无赔付，庄给下家 |
| 一炮多响 | 各赔各的 |
| 转转 | 胡牌者下桌，等待区玩家上桌 |

## 内置的期望值（提示面板会实时给出建议）

| 事件 | 期望金额 | 相对值 |
|---|---|---|
| 我自摸 | +68 元 | 5.4 |
| 别人自摸（我付） | −22.7 元 | 1.8 |
| 我收炮 / 我点炮 | ±12.7 元 | 1 |
| 暗杠 / 大明杠 / 补杠 | +30 / +15 / +15 元 | 2.4 / 1.2 / 1.2 |

由此推出四条打法：

1. **自摸是唯一目标**——收炮与自摸翻的是同一批鸟牌，差别只在「基础」那一项，自摸 ≈ 5.4 倍收炮。
2. **最贵的损失是别人自摸（−22.7）**，比自己点炮（−12.7）还高 1.8 倍；弃和挡不住别人自摸，只有抢胡能挡。
3. **两种听牌抉择**：两面听就放过炮等自摸；单钓或尾盘才收炮。
4. **杠全部必做**；别人碰过的牌的第 4 张打出去是安全的（他不能胡、也不能杠）。

## 怎么玩

- 轮到你时**点击手牌打出**；可以碰/杠/胡时底部会出现按钮
- 快捷键：`H` 胡 · `P` 碰 · `G` 杠 · `空格` 过
- 手机上：第一次点牌是**选中**，再点一次才打出，防误触
- 顶栏「牌况 / 提示」可看实时牌效与收炮抉择建议

## 文件

| 文件 | 说明 |
|---|---|
| `index.html` | 游戏本体，HTML/CSS/JS 全内联，双击即玩，无需联网 |

| `部署说明.md` | 部署与打开方式的完整说明 |

## 本地运行

直接双击 `index.html` 即可（Chrome / Safari / Edge 都行）。
注意：不要用微信、QQ、文件管理器的「预览」打开——那些不执行 JavaScript。
