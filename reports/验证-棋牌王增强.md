## 6. 发现项与可疑项

> 无阻断项。以下问题不改变 t4 验收结论，建议 t6/后续发布任务处理。

### F1（低）页面隐藏时音效/报牌没有全局短路，与方案 4.3 不一致

- **文件/行号**：`index.html:3410`（`sfxCheck` 无 `document.hidden` 判断）、`index.html:3291`（`announce` 同样没有）、`index.html:5520`（`visibilitychange` 只调用一次 `cancelAnnounce()`，之后仍可产生新报牌）；方案原文：`docs/增强方案-棋牌王3D启发.md:363`（“页面隐藏…全部短路”）、`:454`（取消时机）、`:465`（页面隐藏）。
- **现象**：设置 `voice='all'` 后切到后台，AI 回合的 `render → sfxCheck` 仍可能播放事件音并调用 `speechSynthesis.speak`；`visibilitychange` 只清掉切换瞬间的那一条。
- **最小复现**：单机开局 → 设置语音=全部 → 关闭设置 → 切到其他标签页（或等价地把 `document.hidden/visibilityState` 置为隐藏并 dispatch `visibilitychange`）→ 等待电脑行动；可在 stub 中观察到 `speak` 计数在隐藏后继续增加。
- **影响**：后台可听到音效/语音，属体验问题；不涉及规则、数据或安全。
- **建议**：在 `sfx()`/`sfxCheck()`/`announce()` 开头统一判断 `document.hidden`（或维护 `pageHidden` 标志），隐藏时推进游标、不播放、不 speak；恢复可见时从当前事件位置继续。

### F2（低）仓库内 `audio-ui` 的“快进不刷屏”断言可能是空集通过，覆盖不足

- **文件/行号**：`tests/audio-ui.html:113-124`；根因是 `index.html:2399` 的 `if (G.awaiting) return false;`。阶段 3b 在“轮到自己”挂起时把 `fastForward` 设为 true，随后循环第一次调用 `aiStep()` 就因 `G.awaiting` 返回 false 而 `break`，`fastSpoken` 为空；第 123 行 `fastSpoken.every(...)` 对空数组为真，控制台实际打印“快进只报结算，不逐张刷屏：”后为空。
- **影响**：本轮实现经独立 harness 实测正确（快进仅报 `你胡了`），但仓库自身测试不能防止该逻辑未来回归。
- **建议**：在快进循环里加 `if (s.g.awaiting) s.g.autoPlaySeat(s.g.awaiting.seat)`，并断言 `fastSpoken.length > 0` 后再做白名单校验。

### F3（低，发布记录项）构建/缓存版本号未随功能更新

- **文件/行号**：`index.html:6046` `var BUILD = 'v32';`；`sw.js:3` `var CACHE = 'zmj-v32b';`；`tests/offline.test.js:26` 的期望数组仍为 `zmj-v15..v32`；方案 `docs/增强方案-棋牌王3D启发.md:489` 原计划升级 `BUILD='v33' / CACHE='zmj-v33'` 并补 `'zmj-v32b'`。
- **说明**：t4 已声明 `sw.js` 属 `outOfScope`，且 `sw.js:24-32` 对导航是 network-first，因此在线用户下次打开会拿到新 `index.html`；只是首页仍显示“版本 v32”，离线缓存中的旧页面不会因缓存键变化而失效。
